# She-Codes-AASTU-Events-Hub

University event management platform for hackathon.

## Overview

She-Codes-AASTU-Events-Hub is a web application for managing university events and hackathon registrations. It includes a React front end and a Node.js/Express backend, with user authentication, event listings, event detail pages, and registration workflows.

## Features

- User authentication and login
- Event browsing and filtering
- Event detail pages
- Registration for events
- Admin event management
- Responsive user interface

## Tech Stack

- Frontend: React, Vite, JSX
- Backend: Node.js, Express
- Database: MongoDB
- Authentication: JWT
